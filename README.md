# Trionic-8-Decoder-for-Kess-V2-Tools
Hey everyone,
This is a program i wrote in Python to Decode any SAAB Trionic 8 ECU files that have been read by a Kess V2 Tool. 

The Kess V2 Tool does not natively flip the bits in these files. When these files are read, most programs throw an error,
such as "Not a Trionic 8 File" or "Failed Binary Read - Cannot Recognize Maps".
